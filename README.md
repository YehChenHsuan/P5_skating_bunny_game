## 🎮 遊戲簡介與核心特色

《小兔冰上拼讀大冒險》是專為 **ALICE ESL Phonics P5**（Page 04 - 09）兒童美語設計的 3D 溜冰互動拼讀遊戲。孩童化身為靈巧可愛的溜冰小兔，在飄雪的 3D 冰雪樂園中暢快滑行，將純靜態字母與單字認讀昇華為身歷其境的冰上闖關之旅！

### 🌟 三大特色學習模式：
1. **🎧 聽音尋找閃卡 (Word Catch)**：
   - 聆聽標準美語真人發音與字母提示。
   - 滑鼠移動牽引小兔滑行，滑向正確的 3D 冰晶圖卡寶座完成採集！
2. **🥕 首字母尋寶狂歡 (Phonics Challenge)**：
   - 鎖定核心首字母發音：`th, st, ks, ng`。
   - 在冰面上追尋指定字母的漂浮胡蘿蔔冰晶，強化拼讀敏感度。
3. **⛸️ 課本情境動作特技跳躍 (Action Hop)**：
   - 緊扣教材課文與句型（涵蓋 Page 04 - 09 課文活動）。
   - 踩上冰面彩色彈跳板，點擊或按下空白鍵觸發空中 360° 特技旋轉跳躍與金幣彩帶噴發！

## 🕹️ 操作方式與自適應支援
- **電腦滑鼠 / 觸控板**：移動游標平滑牽引小兔滑冰轉向，冰面上即時留下晶瑩冰痕。
- **空白鍵 (Space) / 滑鼠點擊**：施展跳躍特技 (Hop!)。
- **行動裝置（平板 / 手機）**：支援單指輕觸滑行與觸控跳躍。
- **工具箱支援**：支援「提示開關」、「中英雙語發音切換」與「背景音效靜音」。
